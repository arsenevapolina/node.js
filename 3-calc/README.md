# Калькулятор на Node.js

## Описание

Простой калькулятор с модульной архитектурой, где каждая операция вынесена в отдельный файл.

## Структура проекта

- `index.js` - основной файл приложения
- `add.js` - модуль сложения
- `subtract.js` - модуль вычитания
- `multiply.js` - модуль умножения
- `divide.js` - модуль деления
- `repl-demo.js` - демонстрация REPL задачи

## Использование

### Калькулятор

```bash
node index.js <число1> <операция> <число2>
```

Примеры:

```bash
node index.js 5 + 3
node index.js 10 - 4
node index.js 6 '*' 7
node index.js 15 / 3
```

### REPL демонстрация

```bash
node repl-demo.js
```

## Доступные операции

- `+` - сложение
- `-` - вычитание
- `*` - умножение
- `/` - деление

## Обработка ошибок

- Проверка корректности введенных чисел
- Проверка деления на ноль
- Проверка количества аргументов
- Проверка поддерживаемых операций
